# RIM-Analysis-Suite
The RIM Analysis Suite is a MATLAB toolbox developed for Real &amp; Imaginary Mapping (RIM) analysis. It provides a comprehensive workflow to process synchronized optical and electrical signals, enabling the computation and visualization of spatially resolved impedance maps at the electrode-solution interface


# RIM Analysis Suite

This repository contains the RIM Analysis Suite, a MATLAB toolbox designed to compute and visualize spatial impedance maps using synchronized optical and electrical signals.

## System Requirements
*   **Software**: MATLAB R2019b or above.
*   **Dependencies**: Image Processing Toolbox[cite: 2].

## Dataset Availability 
To test this script, the required raw experimental data is hosted on AMS Acta. 

*   **Dataset Title**: “Visualizing Interfacial Dynamics and Reaction Kinetics in Electrochemiluminescence via Reflective Impedance Microscopy”[cite: 1].
*   **Dataset URL**: [https://amsacta.unibo.it/id/eprint/9086/](https://amsacta.unibo.it/id/eprint/9086/)
*   **DOI**: `10.6092/unibo/amsacta/9086`
*   **Contents**: The dataset includes synchronized optical and electrical measurements obtained via a Reflective Impedance Microscopy (RIM) and Electrochemiluminescence Microscopy (ECLM) imaging platform[cite: 1].
*   **Calibration Data**: High-framerate optical image stacks and EC-Lab text exports for calculating the calibration proportionality factor are included in the dataset[cite: 1].
*   **License**: The dataset is distributed under a Creative Commons Attribution 4.0 International (CC BY 4.0) license[cite: 1].
